# SIH-2026
 A project made on the problem id 26059 of SIH 2026.
 This project takes the iceberg data from the past years, checks on their movement, and predicts a path for the movement of the icebergs.
 it also predicts the best for the ships through the icebergs to reach theur desired location.
STEPS:
 1. first run the "iceberg_forecast.py" in your terminal
 2. open the SIH folder
NOTE: if you don't run the python file, the website takes random data to show output
